💸 Jcash Mobile Banking App

Created by: Ludwig Van Flavier

A simple and user-friendly mobile banking application built with Java and JavaFX.

🛠️ Tools Used

Java · JavaFX · Maven · JDBC · MySQL . IntelliJ

✨ Features

  🔐 Register and log in using mobile number and PIN
  👤 Manage user and account information
  💸 Send money
  💰 View account information
  📋 Record and display transaction details
  🔢 Change or reset PIN
  🛡️ Protect PINs using hashing
  🗂️ Organized into UI, services, repositories, models, and security
  🚀 Designed for future improvements and expansion
